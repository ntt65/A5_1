## 공통 가드레일

1. 작업마다 최대 2턴을 사용한다. 1턴에 최소 조회·구현·단일 로컬 검증 배치·기능 단위 로컬 커밋을 마치고, 2턴에 결과만 보고한다.
2. 단 한 번의 오류에도 재시도·추가 수정·후속 명령을 중단하고 핵심 오류와 미완료 범위를 보고한다. 배치 내부도 같은 원칙을 적용한다.
3. `git push`, 원격 PR·이슈 생성, 원격 CI 실행을 금지한다. 이 문서의 이슈/PR 요약은 사용자가 복사할 텍스트다.
4. `force push`, `git reset`, 이력 재작성, 브랜치 삭제, 시스템 재시작을 금지한다. 기존 사용자 변경과 원자료를 보존한다.
5. 전체 트리·대용량 파일·전체 로그 조회를 금지한다. 필요한 경로와 심벌만 `rg`로 조회하며, 시작 시 `log_history.md`는 마지막 5줄만 읽는다.
6. 모든 `*.csv`는 `.gitignore`로 제외한다. CSV 원문·행·샘플 출력은 금지하며 검증 출력은 건수·분할 수·타겟 비율·통계·검증 결과로 한정한다. 기존 CSV는 원문 생성 규칙과 일치하는지 확인하여 재사용하고 원자료를 보존한다.
7. `GridSearchCV`는 항상 `verbose=0`이고 각 탐색의 전체 조합은 50개 이하다. 파라미터당 후보는 5개 이하로 설계한다.
8. `matplotlib.use("Agg")`를 `pyplot` import보다 먼저 적용한다. 모든 그래프는 `savefig`로 저장하고 `close`하며 `plt.show()`는 사용하지 않는다.
9. Python 3.11과 `uv`의 `.venv`를 사용한다. 실행은 `uv run --python .venv python -B -X utf8 ...` 형식이다. 허용 라이브러리는 NumPy·Pandas·Scikit-learn·Matplotlib이며 선택 라이브러리 사용 시 미션의 허용 범위와 버전 명세를 따른다.
10. 커밋은 대상 경로만 `git add -- <경로>`로 스테이징하고 `git diff --cached --check` 성공 뒤 수행한다. 일반 파일은 `git commit --only`에 같은 경로를 명시하여 기존 사용자 스테이징을 보존한다. 기존 CSV의 추적 해제는 아래 작업 1의 격리 인덱스 절차를 사용한다. 메시지는 작업 순서대로 `feat: preprocess`, `feat: modeling`, `docs: report`다.
11. 후속 작업 완료 시 `log_history.md` 끝에 `YYYY-MM-DD HH:mm KST | <chat_id> | <제목>: <한 줄 요지>` 한 줄을 `Add-Content -Encoding utf8`로 추가하고 해당 작업 커밋에 포함한다. 실행 세션의 실제 식별자를 사용하며 식별자가 제공되지 않으면 `unknown`을 기록하고 결과 보고에 밝힌다.

PowerShell 배치는 다음 오류 중단 설정과 래퍼를 사용한다. Bash의 `set -e`에 해당하는 동작을 PowerShell에서 명시한다. 각 외부 명령을 래퍼로 호출하며 실패 이후 명령은 실행하지 않는다.

```powershell
$ErrorActionPreference = 'Stop'
function Invoke-Local {
    param([scriptblock]$Command)
    & $Command
    if ($LASTEXITCODE -ne 0) {
        throw "로컬 명령 실패, 종료 코드 $LASTEXITCODE"
    }
}
```

## 구현 및 산출물 계약

### 데이터와 전처리

- 입력 특성은 `age`, `annual_income`, `spending_score`, `debt_ratio`, `credit_card_count`, `overdue_count_6m`의 6개다. 회귀 타겟은 `credit_score`, 분류 타겟은 `is_overdue`다. 두 타겟 모두 입력 특성에서 제외한다.
- 원본 스키마의 6개 입력은 모두 수치형이다. 수치형에는 `SimpleImputer(strategy='median')`와 `StandardScaler`를 적용하고, 범주형에는 대치와 `OneHotEncoder(handle_unknown='ignore')`를 연결하는 선택 경로를 마련한다. 원본의 범주형 선택 목록은 비어 있다. 범주형 처리 인수 확인은 메모리 내 작은 입력으로 수행한다.
- `preprocess.py`는 명시적인 특성·타겟 상수, 동일 인덱스 분할, 새 전처리 객체 생성 함수를 제공한다. `--validate`는 정상 진입점에서 데이터 구조·분할·대치·인코딩·Train 전용 fit을 확인하고 요약만 출력한다.
- `data_gen.py`는 미션에 제공된 첫 번째 생성 코드 블록을 보존한다. CSV가 이미 있으면 원문 생성 규칙과 검증 결과를 확인해 재사용한다. 기존 자료에 임의 정제·오버샘플링·라벨 변경을 가하지 않는다.

### 모델링

- `baseline.py`는 원본 입력을 사용하는 5개 이상의 명시적 `if`/`elif` 위험 규칙과 최종 정상 반환을 구현한다. 예시 조건은 최근 연체 3회 이상, 부채비율 0.7 초과, 소득 3000 미만, 카드 7개 초과, 최근 연체 1회 이상이면서 부채비율 0.5 초과다. Test 성능으로 규칙을 수정하지 않는다.
- 회귀는 Ridge·Lasso 각각 5개 Alpha를 5-fold `KFold(shuffle=True, random_state=42)`에서 비교한다. 전처리를 포함한 전체 Pipeline을 CV에 넣고 RMSE 기준으로 선택한다. Alpha별 계수는 Train에서 학습한 결과로 저장한다.
- 신용 점수 예측 진입점은 0~1000 clipping을 적용한다. README와 지표에는 이 실제 반환값의 RMSE·MAE·R²를 사용했다고 명시한다.
- 분류는 Logistic Regression과 Random Forest를 사용하고 양쪽에 `class_weight='balanced'`를 적용한다. 분류 기본 임계값은 0.5로 고정하며 해당 선택을 README에 기록한다.
- Random Forest 그리드는 `n_estimators=[100, 200]`, `max_depth=[None, 8]`, `min_samples_leaf=[1, 3, 5]`로 총 12개다. `StratifiedKFold(n_splits=5, shuffle=True, random_state=42)`와 `scoring='f1'`을 사용하고 AUC도 최종 평가한다. 모든 GridSearchCV는 `verbose=0`이다.
- 재현 가능한 분할·추정기의 `random_state`는 42로 고정한다. 검증·튜닝은 Train 8,000건 안에서 수행하며 Test 2,000건은 모든 모델의 최종 비교에 공통으로 사용한다.
- 실제 5개 입력 조건을 적용한 베이스라인의 0/1 출력은 AUC용 규칙 점수로도 사용한다. ML의 AUC와 ROC는 양성 확률로 산출한다. 지표의 `zero_division` 처리를 명시하여 양성 예측이 없는 경우도 유한하게 처리한다.
- `modeling.py --validate` 한 번으로 학습·튜닝·최종 평가·그림 저장·수치 검증을 마친다. 같은 검증 배치에서 전체 학습을 다시 실행하지 않는다.
- 정상 예측 함수는 신용 점수 배열과 연체 확률 배열을 반환한다. `--validate`는 전체 Test 예측의 길이·유한성·범위를 확인하며 고객별 행은 출력하지 않는다.

### 결과 파일

- `artifacts/metrics.json`은 집계 결과만 담는다. 최상위 `regression`에는 `ridge`, `lasso`별 `alpha`, `rmse`, `mae`, `r2`를 기록한다.
- `classification`에는 `rule_based`, `logistic_regression`, `random_forest`별 `accuracy`, `precision`, `recall`, `f1`, `auc`를 기록한다. Random Forest의 최적 파라미터·CV 점수·Confusion Matrix, 베이스라인 점수 방식, 분류 임계값, 데이터 분할 수·시드·특성 목록과 예측 범위 검증 결과도 기록한다.
- `plots`는 저장소 루트 기준의 다음 상대 경로 목록이다. `artifacts/ridge_coefficients.png`, `artifacts/lasso_coefficients.png`, `artifacts/confusion_matrix.png`, `artifacts/roc_curves.png`, `artifacts/feature_importance.png`.
- `feature_importance`에는 Random Forest의 특성 이름과 중요도를 저장하여 README의 3줄 해석을 뒷받침한다.
- 모델 간 우열과 개선율은 실제 지표로 계산한다. 분류 불균형에서 Accuracy만으로 평가할 때의 한계, Precision/Recall 및 임계값의 의미, L1/L2 계수 변화, 합성 데이터와 노이즈에 따른 한계를 설명한다.
